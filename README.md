Willow Tree Drawing with Python Turtle

Description:
This project makes a Python program that draws a willow tree scenery using the turtle module

This program includes basic ideas in Phython graphics, including:
- Drawing shapes(half-circle, rectangle, lines, curved lines)
- Colouring in shapes and spaces
- Uses functions and statements to simplify code

Code Overview:
My project uses the for loop statement combined with the range function to make the willow tree stump.
